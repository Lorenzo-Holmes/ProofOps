# ProofOps 本地 MVP 实现计划

## 目标

实现一个零外部依赖、可在 Windows/macOS/Linux 本地运行的比赛演示系统，覆盖：

1. 六类 Agent 的结构化分工；
2. 证据采集、诊断、修复、审批、执行、验证、回滚闭环；
3. 版本化 Skill 契约与工具网关；
4. 哈希链审计、运行指标和可重复故障样本；
5. HTTP API 与比赛展示用可视化界面；
6. AgentTeams 角色映射和后续真实接入说明。

## 明确边界

- 本地 MVP 使用确定性故障样本，不接触真实生产系统。
- 工具调用通过稳定的 MCP 等价接口建模，默认适配器只操作内置样本。
- AgentTeams 的真实运行需要 Docker 和模型凭据；本仓库交付角色、Skill 与接口材料，并让核心闭环可独立验证。
- 不虚构模型效果；所有指标由本地运行自动计算。

## 交付验收

- `python -m unittest discover -s tests -v` 全部通过；
- 服务启动后 `/api/health` 返回 200；
- 正常样本经人工批准后进入 `resolved`；
- 失败样本验证失败后进入 `rolled_back`；
- 审计哈希链可校验；
- 浏览器界面能够创建事件、逐步/自动执行、审批并显示证据。
